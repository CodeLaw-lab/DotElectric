# Формат листа — строковая идентичность, один каталог

Идентичность стандартного формата листа — строка («A4», «A4×2»), а фиксированный набор форматов живёт в одном доменном модуле `SheetFormatCatalog` (Models). Все поверхности — модель листа (`FromFormat`/дефолтная ориентация), валидатор файлов, список форматов в настройках, меню «Файл > Новый шаблон», кнопки быстрого выбора диалога произвольного размера, дефолт «A3» — потребители каталога. До этого знание было разбросано по 11 точкам (два switch'а в `Sheet`, HashSet валидатора, список настроек, 20 MenuItem с размерами в заголовках, 5 кнопок диалога, парсер суффиксов, шесть копий дефолта), копии расходились (латинское `A4X2` валидно в файлах, но не представимо в настройках; настройка формата по умолчанию была мёртвой).

Решающий довод против enum: формат сериализуется в файл шаблона (.tdel, XML-элемент `Format`) и в settings.json — строковая идентичность уже является границей совместимости файлов. Enum потребовал бы parse-слой на границе файла и создал риск для старых файлов (включая латинские написания полуформатов, которые каталог принимает и нормализует к «×»). Прецедент `ToolKind` (enum) здесь неприменим: идентичность инструментов живёт только в процессе и не сериализуется.

## Considered Options

- **Enum SheetFormatKind + маппинг на границе файла.** Отклонён: сериализуемая идентичность — строка; маппинг добавил бы второй источник написаний и риск совместимости; новый формат по-прежнему требовал бы правок в нескольких местах.
- **Строковая идентичность + один каталог** (принято): новый формат = одна запись каталога; нормализация регистра и «X» → «×» в одном месте; неизвестный формат — единый `ArgumentException` на всех путях (silent-default удалён); поведение байт-в-байт.
- **Оставить копии + pin-тест «XAML совпадает со списком».** Отклонён для меню: копии остаются жить, тест хрупкий; генерация меню из каталога через ItemsSource устраняет 20 пар размеров из XAML.

## Consequences

- Добавление формата: одна запись в `SheetFormatCatalog` — меню, настройки, валидация и создание листа получают его автоматически.
- Пользовательский формат («Custom») в каталог не входит — это открытый путь произвольных размеров (`Sheet.Custom` + спец-кейс валидатора).
- Файлы с латинским написанием полуформатов (`A4X2`) остаются валидными: `Contains`/`TryGet` нечувствительны к регистру и «X»; каноническое имя всегда с «×».
- Если идентичность формата когда-либо перестанет сериализоваться (новый формат файла без строки `Format`) — пересмотреть этот ADR и вариант с enum.
