# Редактор шаблонов DotElectric

CAD-редактор шаблонов .tdel: лист формата, объекты шаблона (линия, прямоугольник, текст), шрифты ГОСТ. Словарь доменных терминов редактора.

## Язык

**Инструмент**:
Режим обработки ввода (мыши и клавиатуры) в редакторе: Выделение, Линия, Прямоугольник, Текст, Ресайз.
_Avoid_: режим, mode

**Пан**:
Вспомогательный жест перемещения вида: зажатая средняя кнопка мыши либо левая кнопка с Space или Alt. Не является инструментом: не имеет идентичности, не переключается через UI и горячие клавиши.
_Avoid_: режим, PanTool

**Активный инструмент**:
Единственный инструмент, обрабатывающий ввод в данный момент. Переключается горячими клавишами V/L/R/T, тулбаром или меню; по умолчанию — Выделение.
_Avoid_: текущий режим, выбранный инструмент

**Стек инструментов**:
Механизм временного модального инструмента: текущий активный инструмент кладётся в стек, активируется модальный (например, Ресайз из Выделения при захвате маркера), по завершении pop возвращает предыдущий.
_Avoid_: история инструментов, очередь

**Вписать в экран**:
Масштаб, при котором весь лист целиком помещается в видимую область редактора (viewport) с отступом. Viewport измеряется в пикселях и обновляется при изменении размеров окна.
_Avoid_: подогнать под окно

**Рамка выделения**:
Прямоугольная область для группового выделения объектов; направление растяжения задаёт критерий: слева направо — объекты, целиком попавшие в рамку, справа налево — объекты, пересекающие её.
_Avoid_: маркиза, лассо

**Предпросмотр**:
Временный контур объекта (линии, прямоугольника или текста), который инструмент рисования показывает во время жеста. Существует до коммита: коммит заменяет предпросмотр финальным объектом в шаблоне, отмена убирает его без следа.
_Avoid_: черновик, preview-объект, эскиз

**Грязность**:
Состояние шаблона, при котором в нём есть несохранённые изменения: в заголовке вкладки появляется индикатор «*». Любое действие, записанное в историю отмен, делает шаблон грязным — включая отмену и повтор действия. Сохранение сбрасывает грязность.
_Avoid_: изменённость, несохранённость

**Маркер выделения**:
Характерная точка выделенного объекта, показываемая квадратом и перетаскиваемая для изменения геометрии объекта: у линии 2 маркера (концы), у прямоугольника 8 (углы и середины сторон), у текста 4 (углы). Захват маркера временно активирует Ресайз через стек инструментов.
_Avoid_: handle, grip, ручка

**Автосохранение**:
Периодическая фоновая запись состояния каждой грязной вкладки в резервные файлы. Не восстанавливает состояние при перезапуске: файлы остаются только для ручного спасения работы после сбоя. Период задаётся в настройках приложения.
_Avoid_: резервная копия сессии, backup

**Стандартный формат**:
Формат листа из фиксированного набора: пять базовых (A0–A4) и пять полуформатов (удвоенная длинная сторона: A4×2…A0×2). Задаёт размеры листа в миллиметрах и ориентацию по умолчанию: A0–A3 — альбомная, A4 и все полуформаты — книжная.
_Avoid_: тип листа, пресет, размер листа

**Пользовательский формат**:
Формат с произвольными размерами, заданными пользователем вне фиксированного набора, в пределах допустимого максимума. В файлах обозначается строкой «Custom», создаётся через диалог произвольного размера.
_Avoid_: произвольный формат, нестандартный формат

**Тема**:
Цветовая схема приложения: светлая или тёмная. Весь интерфейс следует текущей теме; переключение — F9 или через настройки, выбор запоминается между запусками.
_Avoid_: скин, режим оформления

**Сетка**:
Визуальное удобство редактора: отображение точек на листе и привязка к ним при рисовании объектов. Не понятие документа: в файл .tdel не сохраняется, другим приложениям не нужна.
_Avoid_: сетка документа

**Метрики шрифта**:
Соотношения номинального размера шрифта и фактической высоты и средней ширины глифов, по которым из размера шрифта, числа строк и содержимого вычисляются геометрические размеры текста (ширина и высота в микронах). Задаются шрифтами ГОСТ А и ГОСТ Б; при недоступности шрифта действуют запасные значения.
_Avoid_: метрики текста, размеры глифов

**Правила проверки документа**:
Набор правил (V-000…V-007), проверяющих корректность шаблона: структуру и идентификаторы объектов, геометрию объектов относительно листа, форматы цветов, типы линий, формат листа. Живут вместе с документом; проверка выполняется при сохранении: ошибки спрашивают подтверждение пользователя (сохранение при ошибках возможно), предупреждения в решении о сохранении не участвуют. Загрузка файл не проверяет. Проверки полей панели свойств — отдельный механизм редактора.
_Avoid_: бизнес-правила, ограничения

**Объекты шаблона**:
Линии, прямоугольники и тексты, рисуемые на листе и сохраняемые в файл .tdel. У каждого есть идентификатор, положение и размеры в микронах, тип и цвет линии; у текста дополнительно шрифт, содержимое и поворот. Новые типы (например, круг) добавляются по чеклисту расширяемости.
_Avoid_: примитивы, фигуры, графические объекты
